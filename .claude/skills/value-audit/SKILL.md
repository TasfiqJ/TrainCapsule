---
name: value-audit
description: Test whether a feature creates a predeclared, material user outcome without fabricating market or customer evidence.
allowed-tools: Read Grep Glob Bash
---
Evaluate only the frozen value contract and machine evidence. A technically working result that misses the threshold is REDESIGN. Reject lines of code, raw test counts, model praise, synthetic personas, and post-hoc thresholds as value evidence. External demand requires real external behavior or payment.
