# Security policy

TrainCapsule handles potentially sensitive workload evidence. Do not commit credentials, raw customer data, private gate implementations, OAuth material, unrestricted environment captures, or unreviewed incident artifacts.

The repository contains only public gate contracts and references. Hidden gate implementations and release authority remain outside builder-visible paths.

Security findings block promotion until independently reviewed. Unknown, skipped, invalid-oracle, infrastructure-error, or externally-required results are not passes.
