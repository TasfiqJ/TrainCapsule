# Failure capsule rules

Every capsule must contain exact locks, source/raw evidence, transform declaration, expected and observed semantics, oracle provenance, semantic diff, sanitization report, one-command reproduction, and an upstream-style test.

During minimization, after every reduction revalidate fixture legality, oracle integrity, invariant identity, attribution class, and deterministic reproduction. Never publish a synthetic calibration case as a newly discovered production defect.
