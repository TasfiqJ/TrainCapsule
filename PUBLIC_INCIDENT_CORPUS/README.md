# Public incident corpus

This corpus holds redistributable, attributable incidents used to test capture, reduction, replay, localization, qualification, and evidence exchange.

No incident is accepted without a source reference, rights classification, environment description, expected observation, privacy review, and explicit oracle status. Synthetic examples must be labelled synthetic. Missing or uncertain facts remain unknown.

The bootstrap index intentionally contains no invented incidents. Adding the first evidence-backed entries is roadmap work governed by the protected source bundle.
